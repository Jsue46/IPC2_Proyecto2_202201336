# Custom Pointer Data Structures and XML Data Processing in Python

Academic project developed for the **Introduction to Programming and Computing 2** course at the Universidad de San Carlos de Guatemala (First Semester 2024).

This repository contains an object-oriented Python application that implements pointer-based data structures from scratch (linked lists, nodes) without using built-in Python list collections, applied to XML-based data processing and simulation modeling.

---

## Overview

The application parses XML files, populates internal memory models using hand-crafted singly and doubly linked lists, computes simulation states and matrix transformations, and exports results both to terminal reports and visual representations using Graphviz.

---

## Key Features

- Pure pointer-based node and linked list implementations in Python
- Custom XML parser and state loader
- In-memory simulation engine for resource optimization
- Graphviz DOT diagram exports for runtime data verification

---

## Technologies

- **Language:** Python 3
- **Data Exchange:** XML
- **Visualization:** Graphviz (DOT format)
